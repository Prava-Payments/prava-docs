---
title: 'Rotate the Signing Secret'
description: 'Issue a new signing secret, keeping the old one valid for 24 hours.'
icon: 'key'
openapi: '/api-reference/openapi.json POST /v1/webhook-endpoints/{endpointId}/rotate-secret'
playground: 'interactive'
---

Returns a new one-time `signing_secret` and `overlap_hours: 24`. The previous secret stays valid for **24 hours**, so accept both while you update your receiver. See [Security](/webhooks/security).

This request requires an `Idempotency-Key` header and has no body, so omit `Content-Type: application/json`. A retry with the same key returns `{ "replayed": true, "overlap_hours": 24 }` without the secret.

You can't rotate again during the overlap: the request returns `409 WEBHOOK_ROTATION_OVERLAP`.
